    2.0.0
    
    Major refactor: the single-file addon is split into 11 modules loaded from
    the .toc, sharing the private `PI` table. The assignment/comms protocol is
    untouched -- payload shape and wire format are identical to 1.5.x, so this
    does not strand priests on older builds.
    
    New: cooldown alerts for healer priests (Disc/Holy). When the PI target uses
    a tracked cooldown their frame is highlighted, gated on your own PI being
    ready. Detection goes through a Blizzard AuraContainer filtered to tracked
    spell IDs -- the only approach that survives 12.1 secret values, since Lua
    can never read the aura itself.
    
    Also adds packaging guards, which were overdue: a .gitignore for the
    PIHelper reference addon and editor .bak files, and a .pkgmeta ignore list
    covering .claude, CLAUDE.md, check.lua and Sounds.lua. Every .lua in the
    CurseForge zip is now one the .toc actually loads.
    
    Sounds.lua is in the repo but not shipped -- it has no .toc entry, no
    callers and no Options widget, so the alerts feature is visual-only in
    2.0.0. CLAUDE.md is corrected to say so; it had documented the sound path
    as live.
